tiny-paper display

Turns a TRMNL OG, a PicPak or a TRMNL X into a plain e-paper display: plug it into a computer with its USB cable and send it a picture. The guide shows a picture in three commands.

Install

Plug the device in with a USB data cable, then press Install and pick its port ("USB JTAG/serial debug unit").

Installed: now draw on it.

Bluetooth (optional)

Off by default. This step talks to the device over the same cable, after an install or on its own.

    What happens to the device

    • The firmware on it is replaced. After that it does one thing: show the picture you send over the cable. No WiFi, no account, no apps, no updates over the air.
    • Settings the previous firmware stored are left alone: only the firmware's own files are written. The previous firmware itself is gone until you install it again.
    • The device is checked first. If it is not the board you chose, or not one of the three, nothing is written.
    • If the port does not show up: switch the device off, hold its button, switch it on with the cable in, release.

    How to go back

    • Install the firmware the device had, with that firmware's own installer. The display firmware does not stop you: the device can always be flashed again over USB.
    • To be sure you can, read a backup of the whole flash before the first install and keep it: esptool read_flash 0 ALL backup.bin (PicPak: add --no-stub and read the first 16 MB). Writing that file back at 0 restores the device exactly.

    This page loads one library, esptool-js 0.7.0 by Espressif (Apache License 2.0), from jsDelivr when you press Install. Nothing is sent anywhere: the firmware files are read from this site and written to the device by your browser.
